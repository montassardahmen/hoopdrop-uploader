# HoopDrop — Basketball File Uploader 🏀

A responsive drag-and-drop file uploader with a basketball shooting animation, built with **HTML, CSS and vanilla JavaScript**.

## Features
- Drag and drop one or multiple files.
- Browse and select files from your device.
- Camera input on supported mobile devices.
- Basketball animation whenever new files are added.
- Uploaded-file counter, file size display and remove/clear controls.
- Responsive layout for desktop and mobile.
- No frameworks, build tools or API keys required.

## Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or use the VS Code **Live Server** extension.

## Publish on GitHub Pages
1. Create a new public repository on GitHub (for example, `hoopdrop-uploader`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then press **Save**.
6. Wait a minute; GitHub will show your published website URL in the Pages section.

## Important
This is a front-end demo. Files are selected and displayed in the browser only; they are **not sent to a server or stored online**. To make real uploads available to an admin or other users, connect a backend or storage service.
