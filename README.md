# HoopDrop — Basketball File Uploader 🏀

A responsive drag-and-drop file uploader with a basketball shooting animation, built with **HTML, CSS and vanilla JavaScript**.

## Features
- Drag and drop one or multiple files.
- Browse and select files from your device.
- Camera input on supported mobile devices.
- Basketball animation whenever new files are added.
- Uploaded-file counter, file size display and remove/clear controls.
- Responsive layout for desktop and mobile.
- No frameworks, build tools or API keys required.
